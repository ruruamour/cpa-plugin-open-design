添加账户

填写标签和 API key 后添加。
可选：额度查询（官方 control key）

填写同一 OpenDesign 账号的额度授权。只填 controlKey 可查钱包；再填 Workspace ID 可查套餐窗口。 新增账户时两项均可留空；已保存的 controlKey 不会回显。

编辑时留空表示保留原值；勾选后保存可清除额度授权，推理 Key 保留。
