填写标签和 API key 后添加。

可选：额度查询（官方 control key）

填写同一 OpenDesign 账号的额度授权。只填 controlKey 可查钱包；再填 Workspace ID 可查套餐窗口。 新增账户时两项均可留空；已保存的 controlKey 不会回显。

编辑时留空表示保留原值；勾选后保存可清除额度授权，推理 Key 保留。

错误规则

作用范围：全部 OpenDesign 凭据。规则保存在插件中，并随每个账号的凭据同步给 CPA；实际的换号与冷却决定由 CPA 做出。

动作说明

停止

当前请求：停止重试和切换凭据，把错误返回客户端。

后续调度：不影响凭据的冷却状态。

停止并冷却

当前请求：停止重试和切换凭据，把错误返回客户端。

后续调度：把失败的凭据或模型暂时排除出调度。

继续

当前请求：继续尝试其他可用候选账号。

后续调度：不冷却失败的凭据。

继续并冷却

当前请求：继续尝试其他可用凭据。

后续调度：冷却期间跳过失败的凭据。

匹配方式

「包含文本」按子串匹配上游错误文本；「正则表达式」使用 Go 正则语法。状态码必须与上游返回的 HTTP 状态一致，两者都命中才会触发动作。

规则为空时

没有规则时不写入插件自有规则，改由 CPA 自身的配置决定分类与调度。
